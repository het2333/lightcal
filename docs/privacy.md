# LightCal 隐私说明

更新日期：2026 年 10 月 19 日。适用于 iOS 本机版 0.2.0。

## 本机记录

饮食、餐食照片、体重、饮水、运动、睡眠、断食、目标、偏好和提醒保存在应用沙盒中。LightCal 不提供开发者服务器账户、云同步、公开动态或广告追踪。系统设备备份行为由你的 iOS 设置决定。

你可以在设置中导出本机 JSON 记录或删除记录。导出文件包含私人健康记录和已保存的餐食照片，请自行保管。API Key 不包含在导出文件中。删除本机记录不会删除 Apple 健康中的原始数据，也不会撤销已由你导出的文件。卸载应用可能丢失记录，请先导出需要保留的数据。

## 通义千问与阿里云百炼

AI 功能使用你自己的百炼账户和 API Key。Key 存在本机、仅解锁时可用的设备专属系统钥匙串中，不写入普通偏好设置、记录文件或导出文件。应用仅向你选择地域的阿里云百炼 HTTPS 接口发送鉴权，禁止重定向；不会将密钥交给开发者服务器。

首次使用前，需要在“千问设置”中明确同意数据发送：

- 图片识别发送你主动选择或拍摄的主照片及辅助照片。
- 聊天发送你的问题和最近对话；文字估算发送你输入的食物描述或语音转写文本。
- 仅在另行开启“聊天时结合我的记录”后，聊天才发送最近 7 天的饮食、饮水、体重、运动和偏好。默认关闭此选项。
- “验证并保存”向聊天和图片模型各发送一句测试文字，不发送你的照片或健康记录。

你可以选择中国内地、新加坡或美国地域，需与 Key 和模型权限对应。相关内容由该地域的阿里云服务处理。百炼可能按其政策存储调用产生的数据；其保留、使用和跨境处理规则请查阅[百炼数据隐私说明](https://help.aliyun.com/zh/model-studio/privacy-notice)及你的百炼账户协议。调用费用由你的百炼账户结算。

关闭授权或关闭记录发送会立即保存在本机，阻止之后的新请求按旧授权发送。撤回不能收回已经发出的请求或内容；对第三方已处理的数据，请依据其政策联系阿里云。设置中可以删除密钥和授权；系统钥匙串在卸载后是否保留由系统机制决定，请在卸载前主动删除不需要的密钥。

## 系统权限

相机和照片权限用于拍摄或选择餐食图片。麦克风及 Apple 语音识别用于用户主动发起的语音转写；转写可能由 Apple 服务处理，受系统权限与 Apple 政策约束。

Apple 健康仅在你主动授权后读取步数、活动能量、体重、饮水和睡眠，并可将你确认保存的营养写入健康。健康记录用于饮食记录和汇总，不用于广告、营销或数据交易。只有你另行同意向千问发送记录时，相关汇总或记录才会作为聊天参考发送给阿里云。可在系统健康设置中随时撤销健康权限。

通知权限用于你主动设置的本机提醒。拒绝可选权限不会阻止手动记录。

## 说明与联系

AI 营养、克重与饮食建议均可能有误，不构成诊断、治疗或专业医疗建议。请自行检查份量与营养数据。

问题反馈与隐私请求：[LightCal GitHub Issues](https://github.com/het2333/lightcal/issues)。反馈时请勿公开 API Key、个人照片或健康数据。
